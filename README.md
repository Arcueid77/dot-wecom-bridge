# dot-wecom-bridge

把本人企业微信私聊接到原来的 ChatGPT dot。通过企业微信**智能机器人长连接模式**接收消息，再由官方 Secure MCP Tunnel 交给 dot，最终回复回到原私聊。

本仓库负责企业微信收发，共享运行和存储能力由 `dot-bridge-core` 提供。需要同时使用多个聊天应用时，从 [DotBridge 总仓库](https://github.com/Arcueid77/dot-bridge)安装和管理。

需要企业管理员在管理后台创建支持长连接的智能机器人，取得 Bot ID 和长连接 Secret。运行配对命令后，在本人和机器人的私聊里发送临时口令，就能保存本人绑定。这里接入的是智能机器人，不适用于仅能发消息的群机器人 Webhook，也没有提供自建应用 XML 回调模式。

支持本人私聊文字、图片和文件。图片与文件可以下载、解密后交给 dot；收到语音时，企业微信提供的是转写文字，没有原始音频。dot 可以回复文字、图片、已有 AMR 语音或文件。视频目前只显示类型提示。

单个附件最多 8 MiB；发送语音需为 AMR、最多 2 MiB。每条原消息对应一个最终回复，可以选文字或一个附件；附件不附带说明文字，文字最多 6,826 个字符。[具体格式与限制](docs/media.md)。

同一个机器人只运行一套消费者。如果收到“另一连接已接管”的通知，这套桥会断开并停止抢连；处理重复实例后再由运维重启。安装和原 dot 订阅步骤见[配置与使用](docs/configuration.md)。
