# 附件与回复

[English](media.en.md)

| 内容 | 发给 dot | dot 回复到本人私聊 |
| --- | --- | --- |
| 文字 | 支持，保留图文中的文字 | 最多 20,000 字符；超过原生单条限额后以完整文字文件回复 |
| 图片 | 支持读取、解密 PNG、JPEG、GIF | PNG、JPEG、GIF |
| 语音 | 企业微信提供的转写文字；没有原始音频 | AMR 文件，最多 2 MiB |
| 文件 | 支持下载和解密原文件 | 支持原文件 |
| 视频 | 只显示附件类型 | 暂不提供 |

单个附件最多 5 MiB。企业微信的附件地址只有五分钟有效期，dot 应收到消息后尽快读取。如果已过期，请重新发附件；不能通过重试恢复一个过期地址。

`get_wecom_message` 提供消息文字和附件列表，`get_wecom_attachment` 读取其中一张图片或一个文件。语音直接使用消息里的平台转写，不需要再调用附件工具取音频。转写不能反映音色、语气或背景声音，回复时也不应声称听到了原始录音。

`reply_to_wecom` 回复文字，`reply_wecom_media` 回复单个附件。文字回答最多 20,000 字符；超过原生单条 6,826 字符或 20,480 UTF-8 字节时，完整回答作为一份 `answer.txt` 文件回复。每条原消息只对应一个最终回复；附件暂不附带说明文字。语音回复需要现成的 AMR 音频，桥本身不生成语音，也不把其他音频格式自动改后缀发送。

媒体回复先按 512 KiB 分片上传到企业微信，再用原消息的回调标识回复。只有收到对应确认才会完成；断线或回执超时会保留“结果不明”，不会换成主动群发或自动重发。发送到企业微信不代表用户已经阅读。

图片和文件的下载、解密在桥端完成，下载地址与每个文件的解密 key 不会交给 dot。只访问已识别的官方 HTTPS 地址，不跟随跳转；遇到未识别的官方下载节点，需要运维核对后处理。

协议依据：[企业微信智能机器人长连接文档](https://developer.work.weixin.qq.com/document/path/101463)，以及官方 [Node SDK 媒体 API](https://github.com/WecomTeam/aibot-node-sdk/blob/main/src/client.ts) 和[文件解密实现](https://github.com/WecomTeam/aibot-node-sdk/blob/main/src/crypto.ts)。
